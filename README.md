# Mineiration-Bitcoin-: Escritório Virtual de Mineração

Aplicação web em que **25 agentes** acompanham mineração de Bitcoin com **dados reais** (fonte, horário e idade de cada número) num escritório 3D, e **pausam quando a conta dá prejuízo**.

> **Aviso:** nada aqui é aconselhamento financeiro, jurídico ou tributário. Mineração pode dar prejuízo, e o projeto não promete lucro. Máquinas em 3D não mineram: a mineração real vem de hashrate alugado ou ASICs hospedados; a Fase 1 é só simulação.

## Estado atual
Fase de design. **Ainda não há código de produto.** Entrega 1 prevista: Fase 1 (simulação com dados reais, sem dinheiro).
